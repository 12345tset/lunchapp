# 🍱 학교 급식 알레르기 안심 알리미 웹 앱

교육부 나이스(NEIS) 오픈 API를 활용하여 전국의 학교 급식 식단을 조회하고, 사용자가 선택한 알레르기 유발 성분이 포함된 메뉴를 실시간으로 빨간색으로 강력하게 강조 표시해 주는 웹 애플리케이션입니다.

---

## 🚀 실행 방법

별도의 서버 설치 없이 브라우저(Chrome, Edge, Whale 등)에서 바로 열어서 사용할 수 있는 단일 HTML 앱입니다.

1. `index.html` 파일을 더블 클릭하여 웹 브라우저에서 실행합니다.
2. 또는 터미널(PowerShell)에서 아래 명령어를 실행하여 기본 브라우저로 엽니다:
   ```powershell
   Start-Process index.html
   ```

---

## 🌟 주요 기능

1. **나이스(NEIS) Open API 연동**
   - 사용자 인증키: `69863915deb14ed9896c70591977d66f`
   - 학교 기본정보 API (`schoolInfo`)를 통한 전국 초·중·고·특수학교 검색
   - 급식 식단정보 API (`mealServiceDietInfo`)를 통한 일자별 조식/중식/석식 조회

2. **19대 법정 학교급식 알레르기 유발 물질 체크박스**
   - 1.난류(달걀), 2.우유, 3.메밀, 4.땅콩, 5.대두(콩), 6.밀, 7.고등어, 8.게, 9.새우, 10.돼지고기, 11.복숭아, 12.토마토, 13.아황산류, 14.호두, 15.닭고기, 16.쇠고기, 17.오징어, 18.조개류, 19.잣
   - 사용자가 체크박스를 클릭하거나 변경하면 **API 재호출 없이 실시간으로 강조 스타일 반영**
   - "자주 겪는 알레르기", "선택 해제" 바로가기 버튼 제공

3. **강력한 알레르기 시각적 경고**
   - 알레르기 유발 식재료가 들어간 메뉴는 **선명한 빨간색 배경(`rgba(254, 226, 226)`), 2px 빨간색 테두리(`border: 2px solid #dc2626`), 볼드체 및 금지/주의 아이콘(⛔)**으로 즉각 강조
   - 식단 카드 상단에 펄스 애니메이션이 적용된 **경고 배너** 노출
   - 각 음식에 포함된 알레르기 성분 번호 배지 중 선택된 항목을 붉은색 배지로 하이라이트

4. **사용자 편의 기능**
   - 날짜 선택 달력, 이전 날 / 다음 날 / 오늘 바로가기 이동 버튼
   - 마지막으로 조회한 학교 및 선택한 알레르기 항목을 `localStorage`에 자동 저장
   - 원산지 정보 및 영양성분 정보 아코디언 접기/펼치기 제공
